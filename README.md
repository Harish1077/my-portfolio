#  Overview

This repository contains my personal portfolio website built to showcase:

- Projects
- Technical skills
- Development experience
- Certifications
- Contact information
- Professional profile

The portfolio is designed with a modern UI/UX approach and responsive design principles to provide a seamless experience across devices.

It serves as a digital presence for recruiters, developers, and collaborators to explore my work and technical journey.

#  Installation & Setup

## Clone Repository

```bash
git clone https://github.com/Harish1077/my-portfolio.git
```

## Navigate to Project

```bash
cd my-portfolio
```

## Install Dependencies

```bash
npm install
```

---

#  Run the Project

## Development Server

```bash
npm run dev
```

or

```bash
npm start
```

The application will run on:

```bash
http://localhost:3000
```
